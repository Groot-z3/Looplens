# LoopLens – Infinite Loop Detection

LoopLens is a browser-based educational tool that demonstrates restricted infinite-loop detection using static analysis.

## Features
- Detects common infinite-loop patterns.
- Identifies simple terminating counter loops.
- Provides step-by-step execution traces.
- Explains the Halting Problem, Turing Machines, decidability and recognizability.
- Includes sample programs for testing.

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Getting Started
1. Clone or download this repository.
2. Open the project folder.
3. Run `index.html` in your browser.

## Note
LoopLens performs limited pattern-based analysis. It does not execute arbitrary Python programs or solve the general Halting Problem.
