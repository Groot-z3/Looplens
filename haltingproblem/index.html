The Halting Problem

Given an arbitrary program and its input, determine whether it eventually stops or continues forever.

GENERAL HALTING IS UNDECIDABLE

Can an algorithm always decide?

A decision problem is decidable if an algorithm halts on every valid input and returns the correct yes/no answer.

The general Halting Problem is undecidable: no such algorithm works correctly for all program-input pairs.

Recognize, not decide

The set of programs that halt is recognizable: simulate the program; if it halts, accept. If it runs forever, the simulation also runs forever.

This does not provide a terminating yes/no answer for every input.

A model of computation

A Turing Machine has a finite control, an unbounded tape, a tape head and transition rules. It provides a formal model for describing general computation.

It may enter an accept/reject state or continue computing indefinitely.

The contradiction idea, informally

AssumeA perfect tool H predicts whether any program halts.
→
ConstructA program D that does the opposite of H's prediction about D itself.
→
ContradictionWhether D halts, its behaviour contradicts H's answer.

This diagonalisation argument shows that the assumed perfect predictor cannot exist.

Analyze a restricted subset

Real tools can still detect useful cases by limiting the language or using conservative rules: constant conditions, unchanged loop variables, simple monotonic counters and bounded simulations.
